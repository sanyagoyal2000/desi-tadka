DesiTadka — how it's built

One Next.js app on your laptop, opened on your phone. yt-dlp + ffmpeg pull the reel apart; OpenAI (by API key or your local Codex) turns it into a card.

The system at a glance

API key mode

  • AI_MODE=api + OPENAI_API_KEY
  • Calls the OpenAI API directly
  • Swaps get an AI-generated picture

Local Codex mode

  • AI_MODE=codex + CODEX_PATH
  • Runs the Codex CLI you're logged into, so no key is needed
  • No image generation: reel frame + "swapped" badge

Follow one reel through the system

Components

Convert View app/convert/page.tsx

Original card, "convert?" prompt, swap icons, Make it vegetarian, workout swap counter (max 3), Save. The in-progress card lives in React state and is discarded unless saved.

Recipe Swaps (the star)Workout Swaps
AI Provider lib/ai/

One interface, two implementations chosen by AI_MODE: extractCard, suggestSwaps, applySwaps, makeVegetarian, generateImage. Prompts tell the model the audience is in India and to use commonly available Indian ingredients. Every response is validated with zod, with one retry.

openaiApi.tscodexCli.tsprompts.ts
Reel Extractor lib/reel.ts

yt-dlp downloads the video and info JSON (the caption is in description); ffmpeg saves 4–6 frames to public/media/<id>/. A typed "inaccessible" error drives the fallback.

Home Page app/page.tsx

Link box with instant validation ("Wrong link"), and a saved list with thumbnail, name, and type tag. Shows the empty state when there are no cards, and a setup banner when neither a key nor a Codex path is set.

When things break

What breaksWhat you see
Not an Instagram link"Wrong link" (no server call)
yt-dlp blocked / private reel"Unable to access, please check" + paste-caption box
Broken AI JSONOne retry, then "Couldn't read this reel, try again"
Not a recipe or workout"This doesn't look like a recipe or workout"
No key and no Codex pathSetup banner on Home

Verify first in the build

  • yt-dlp can fetch one real public reel and its caption.
  • codex exec --help: flags for attaching images and getting JSON back.
  • Current OpenAI model names (kept in .env.local, not hardcoded).
  • Nutrition is AI-estimated, so label it "approx."
